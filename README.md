## Install

1. Download the latest `OneMix.app` from the [Releases page](https://github.com/mbouli/onemix/releases/latest).
2. Move `OneMix.app` into your **Applications** folder.
3. Open OneMix. Its icon appears in the menu bar.

OneMix requires macOS 26 or later.

On first launch, macOS asks for a couple of permissions:

- **System Audio Recording**: lets OneMix change each app's volume. Audio never leaves your Mac.
- **Control Music**: lets OneMix set Apple Music's own volume, so Dolby Atmos and Spatial Audio keep working.

If macOS says OneMix can't be opened because it's from an unidentified developer, go to **System Settings → Privacy & Security** and click **Open Anyway**.
